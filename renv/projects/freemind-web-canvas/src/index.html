Bantuan & Pintasan

Navigasi & seleksi

  • Klik/tap pilih · Shift+klik = multi-pilih
  • Shift+seret latar = seleksi kotak
  • Tombol panah = pindah seleksi · Ctrl+klik link = buka
  • Scroll/cubit/tombol ± = zoom · seret latar = pan

Node

  • Dobel-klik = edit · Tab = anak baru · Enter = saudara baru · Del = hapus
  • Ctrl+↑/↓ = naikkan/turunkan urutan node di antara saudara
  • Klik lingkaran tepi atau Space = fold
  • Geser node = pindah · geser oval tepi = atur posisi (Ctrl = jarak saudara)
  • Shift+Tab = indentasi teks · Shift+Enter = baris baru saat mengedit

Panel kanan

  • Catatan/ikon/warna/gaya/edge/font/atribut

Menu Insert

  • Ringkasan Baru = ringkas saudara terpilih
  • Panah ke Node Terpilih = hubungkan node (yang pertama jadi sumber)

Panah

  • Panah terpilih: seret titik kontrol/garis untuk pindah edge/tekuk

Pintasan

  • Ctrl+C/X/V/D · Ctrl+Z/Y · Ctrl+F cari, F3 berikutnya
  • Ctrl+S simpan · Ctrl+Shift+S unduh .mm · Ctrl+O buka
  • Tab: Ctrl+T baru, Ctrl+W tutup, Ctrl+Tab ganti · dobel-klik nama tab = ubah

Penyimpanan

  • Tersimpan otomatis di peramban · menu File untuk pulihkan/hapus
  • Peta tab yang ditutup dipindah ke Riwayat (File > Riwayat Peta Ditutup), tidak langsung hilang
