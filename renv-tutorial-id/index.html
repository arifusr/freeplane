Apa itu renv

renv menyimpan seluruh state riset ke dalam satu file SQLite. Klien (CLI, MCP, dan web cockpit) hanya lapisan tipis di atas domain functions yang sama, jadi tidak ada salinan kedua dari apa pun.

  • Satu store, klien tipis. DB SQLite adalah ground truth; tidak ada state ganda.
  • Sitasi ter-anchor span. Anchor-nya adalah teks kutipan itu sendiri, diverifikasi terhadap klaim.
  • Eksperimen sebagai DAG. Satu eksperimen, satu pertanyaan; bercabang alih-alih mengubah.
  • Provenance ditegakkan. Angka hanya boleh masuk lewat run yang tercatat.
  • Klaim tertaut bukti. Status supported/refuted dihitung, bukan diketik.
  • Angka di-weave. Tabel hasil & bibliografi diregenerasi dari store.

Instalasi

Prasyarat: uv (Python 3.10+); build cockpit memerlukan Node.

git clone https://github.com/julianwinking/renv-ai renv
cd renv
uv sync

# taruh paper .txt/.md/.pdf di library/, lalu:
uv run renv index

Alur riset inti

  1. Daftarkan paper. renv add <pdf|arxiv|doi> lalu renv index.
  2. Buat klaim. renv claim add <proyek> "teks" --kind thesis.
  3. Kutip span. renv cite "teks klaim" <proyek> --source <key> --write.
  4. Tautkan bukti. renv claim link <id> --cite <N> --stance supports.
  5. Weave & ekspor. renv weave <proyek> dan renv export.

Tips: susun teks klaim mendekati frasa sumber — verifier lexical default menilai tumpang tindih token, bukan entailment.

Menghubungkan agen lewat MCP

Server MCP stdio menyediakan 57 tool. Contoh konfigurasi klien:

{
  "mcp": {
    "renv": {
      "type": "local",
      "command": ["uv", "run", "--directory", "/path/ke/renv", "renv", "mcp"],
      "enabled": true
    }
  }
}
