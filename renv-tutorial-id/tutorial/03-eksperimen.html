Eksperimen & Run

Eksperimen membentuk DAG: satu eksperimen, satu pertanyaan. Angka hasil tidak boleh diketik — hanya boleh masuk lewat run yang tercatat.

3.1 Membuat eksperimen (DAG)

uv run renv exp new span-citation 001-tfidf --title "TF-IDF baseline"
uv run renv exp new span-citation 002-dense --parent 001-tfidf

uv run renv exp list span-citation
uv run renv exp show span-citation 001-tfidf

Gunakan --parent untuk bercabang alih-alih mengubah eksperimen yang sudah selesai.

3.2 Kontrak entrypoint

Sebuah entrypoint membaca lokasi output dan parameter dari environment, lalu menulis metrics.json:

Env varArti
RENV_RUN_DIRDirektori tempat menulis metrics.json.
RENV_PARAMSParameter dari --param (JSON).

Setiap run mem-pin git sha, env hash, dataset, config hash, dan seed.

3.3 Menjalankan

uv run renv exp run span-citation 001-tfidf \
  --entrypoint run.py --param k=8

Eksperimen panjang berjalan di latar belakang sehingga tidak memblokir agen.

3.4 Log keputusan & invariant provenance

# angka hanya boleh masuk lewat run yang tercatat
uv run renv log add span-citation result "recall hit 0.8" --evidence run:1

# audit seluruh store terhadap invariant provenance
uv run renv log check
Sebuah entri log bertipe result ditolak bila tidak menautkan run yang selesai. Ini menjamin provenance, bukan validitas — run yang salah tetap bisa menghasilkan angka keliru.

3.5 Dataset

uv run renv dataset add --slug squad --path data/squad.json --version v1

Dataset direkam versioned dan content-hashed; run menautkan dataset yang dipakai.

3.6 Run di cluster (remote)

Bila komputasi/data tetap di cluster, daftarkan remote (alias ssh) lalu ingest hasilnya dengan provenance bergradasi remote / remote-verified: 

uv run renv remote add snaga --host snaga --data-root /scratch/me
uv run renv dataset add --slug imagenet --location ssh://snaga/data/imagenet --sha256 <hash-di-cluster>

# setelah run di cluster
uv run renv exp ingest span-citation 002-dense --dir runs/002-dense
# atau tanpa membawa data pulang:
uv run renv exp ingest span-citation 002-dense \
  --metrics '{"recall":0.83}' --remote ssh://snaga/runs/exp42

3.7 Dari hasil ke paper

Angka mengalir run → metric → paper melalui renv weave (Bab 04). Kurva per-step (TensorBoard, dsb.) adalah artefak TELESCOPE — tidak pernah bisa disitasi.
