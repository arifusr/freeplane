Menulis Manuskrip

Teks paper hidup di text/. Angka dan bibliografi tidak diketik — keduanya di-weave dari store agar manuskrip tidak bisa melenceng dari data.

4.1 Scaffold teks

uv run renv draft span-citation      # (ulang) scaffold skeleton paper di text/
ls projects/span-citation/text/

4.2 Preamble & \spancite

Cetak definisi LaTeX untuk perintah sitasi span, lalu sertakan di preamble:

uv run renv preamble

Sitasi yang dihasilkan renv cite siap ditempel ke teks:

\spancite{gao2023_alce}{579}{783}{Unlike commercial search assistants that cite
an entire web page, ALCE cites at the granularity of short hundred-word passages.}

4.3 Menautkan sitasi ke lokasi manuskrip

Klaim dapat diberi manuscript_loc agar direview tertaut ke bagian teks tertentu. Review otomatis akan menandai klaim tesis yang masih open. 

uv run renv review span-citation      # cek per-section
uv run renv finding list span-citation
uv run renv finding adjudicate <id> --verdict accept --reasoning "..."

4.4 Weave: hasil + bibliografi

uv run renv weave span-citation

Menghasilkan (diregenerasi dari store):

  • text/results_table.tex — tabel hasil dari metric rows.
  • text/references.bib — bibliografi dari corpus.
  • text/preamble.tex — definisi \spancite.
  • citations.json — sidecar sitasi (turunan).
Angka diturunkan, tidak diketik. Karena tabel dan bibliografi dihasilkan store, manuskrip selalu konsisten dengan run dan corpus.

4.5 Kompilasi PDF

uv run renv compile span-citation
# = weave + kompilasi text/ ke PDF (latexmk / tectonic / pdflatex)

4.6 Snapshot untuk git

uv run renv export      # snapshot JSONL deterministik ke .research/export/

.research/env.db di-gitignore; yang dikomit adalah snapshot JSONL, sehingga diff-nya rapi dan dapat direstorasi dengan renv import.
