Klaim & Sitasi

Jantung renv: setiap klaim harus bersumber. Sitasi mengikat klaim ke span teks yang tepat di paper sumber, dan status klaim dihitung dari bukti — bukan diketik manual.

2.1 Konsep: span-anchored citation

Anchor sitasi adalah teks kutipan itu sendiri (W3C TextQuoteSelector + TextPosition). Karena tidak bergantung pada id chunk/vektor, anchor tetap valid setelah re-index atau pergantian versi dokumen. Emitted sebagai LaTeX \spancite{src}{start}{end}{quote}.

2.2 Membuat klaim

Klaim punya kind yang menentukan perannya dalam argumen:

KindArti
thesisTesis utama paper.
contributionKontribusi yang diklaim.
assertionPernyataan faktual pendukung.
hypothesisKlaim yang menunggu pengujian (dipasangkan ke eksperimen).
 
uv run renv claim add span-citation \
  "ALCE cites at the granularity of short hundred-word passages" \
  --kind thesis

2.3 Mengutip span

uv run renv cite "ALCE cites at the granularity of short hundred-word passages" \
  span-citation --source gao2023_alce --write

Contoh keluaran:

CLAIM: ALCE cites at the granularity of short hundred-word passages
SUPPORT: full (1.0)  sim=0.5708
SOURCE: gao2023_alce chars 579-783 (page 1)
QUOTE: “Unlike commercial search assistants that cite an entire web page,
ALCE cites at the granularity of short hundred-word passages…”
citation row: #2 → paper gao2023_alce
  link it: renv claim link <claim-id> --cite 2
Verifier lexical vs factcg. Verifier default (lexical) menilai tumpang tindih token, bukan entailment — parafrase yang benar bisa bernilai none. Untuk verifikasi semantik gunakan --verifier factcg (butuh extra verify-local).
Verdict none ditolak tanpa --force.

2.4 Menautkan bukti ke klaim

uv run renv claim link 1 --cite 2 --stance supports --grade suggestive

# stance: supports | refutes | inconclusive
# grade:  anecdotal | suggestive | confirmatory

Satu panggilan cite meng-anchor SATU span. Klaim dengan k sumber memerlukan k ronde cite+link, masing-masing dengan --source sendiri.

2.5 Merawat sitasi

uv run renv claim list span-citation       # status diturunkan dari bukti
uv run renv claim show 1                    # detail + bukti tertaut
uv run renv citation list span-citation    # semua baris sitasi
uv run renv citation rm 3 --force          # tombstone (bukan hapus; history tetap)

2.6 Menghubungkan antar klaim

uv run renv claim relate 2 1 --kind depends_on
uv run renv claim relate 5 1 --kind contradicts

depends_on dan contradicts membentuk struktur argumen (bukan bukti) dan tidak mengubah status turunan.

Trik penulisan. Susun teks klaim mendekati frasa sumber. Bila tahu paper-nya, pin --source <key> agar pencarian tidak melenceng.
