MCP untuk AI

renv menyediakan server MCP stdio sehingga agen dapat menjalankan seluruh loop riset melalui jalur kode dan batasan yang sama dengan CLI.

5.1 Menjalankan server MCP

uv run renv mcp          # server stdio (untuk klien MCP)

Konfigurasi klien (contoh gaya umum):

{
  "mcpServers": {
    "renv": { "command": "uv", "args": ["run", "renv", "mcp"] }
  }
}
Karena corpus diresolusi relatif terhadap direktori kerja, jalankan dengan cwd di root repo renv. Contoh untuk klien yang tak punya opsi cwd: uv run --directory /path/ke/renv renv mcp.

5.3 Protokol operasi (AGENTS.md)

Berkas AGENTS.md di root repo adalah protokol yang diikuti agen. Ringkasnya:

  1. Pulihkan konteks dulu — exp list + log list sebelum bekerja.
  2. Sumberi setiap klaim — pekerjaan sebelumnya via cite_claim; hasil via run tercatat.
  3. Log sebelum berpindah arah — keputusan sebagai decision, item terbuka sebagai question.
  4. Satu eksperimen, satu pertanyaan — cabang via --parent.
  5. Hasil dihasilkan, tidak diketik.
  6. Snapshot dengan renv export.

5.4 Jalur baca aman

# SQL read-only (SELECT/WITH) lewat MCP tool `query`
SELECT id, text, kind, status FROM claim WHERE project_id = 1;

# pencarian teks penuh di papers/cards/notes/log/claims
uv run renv search "telephone effect"
Jangan buka file SQLite langsung. Escape hatch resminya adalah renv query (CLI dan MCP query identik).

5.5 Menutup loop

Dengan MCP aktif, agen dapat menjalankan seluruh siklus — indeks corpus, buat klaim, kutip span, catat run, weave — melalui batasan yang sama seperti manusia di CLI. Hasilnya: state riset yang dapat diaudit.
