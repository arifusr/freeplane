Instalasi & Setup

Menyiapkan renv di mesin lokal, membangun corpus referensi, dan membuat project riset pertama.

1.1 Prasyarat

  • uv (pengelola Python + virtualenv) — wajib, Python 3.10+.
  • git — untuk mengkloning repo dan versi project.
  • Node.js — hanya jika ingin membangun web cockpit.
  • sqlite3 — opsional, untuk inspeksi manual (renv sendiri memakai query).
  • latexmk / tectonic / pdflatex — opsional, untuk kompilasi PDF manuskrip.

1.2 Kloning & sinkronisasi dependensi

git clone https://github.com/julianwinking/renv-ai renv
cd renv
uv sync

Inti renv berjalan dengan stdlib + satu dependensi kecil (pdfminer.six). Backend SOTA (embedding lokal, verifier NLI) adalah extras yang di-lazy import: 

# contoh menambah verifier semantik
uv sync --extra verify-local

1.3 Struktur repositori

PathIsi
renv/Engine: indexing, anchoring, verifikasi, store, eksperimen, weave, CLI, MCP.
library/Corpus referensi bersama (paper .pdf/.txt/.md).
.renv/Index turunan + lockfile (dapat diregenerasi).
.research/env.dbGround truth: SQLite pusat semua state.
projects/<slug>/Satu paper: src/, text/, runs/ (repo git sendiri).
AGENTS.mdProtokol operasi untuk agen (dan manusia).

1.4 Daftarkan paper & bangun index

Letakkan file paper di library/, lalu indeks. Metadata paper didaftarkan lewat renv add:

# dari file lokal
uv run renv add library/gao2023_alce.txt --key gao2023_alce \
  --title "ALCE: Automatic LLM Citation Evaluation" --year 2023

# dari arXiv / DOI (unduh PDF sekaligus)
uv run renv add 2305.14627 --download
uv run renv add 10.1162/tacl_a_00638

# dari BibTeX (cold-start)
uv run renv add refs.bib

# bangun index setelah apa pun masuk ke library/
uv run renv index
Identitas paper. File yang mendarat selalu dinamai <key>.ext. Menjalankan renv add dengan --key yang sudah ada akan melampirkan teks ke paper itu.

1.5 Inisialisasi store & project

uv run renv db init                       # buat/migrasi .research/env.db
uv run renv project new span-citation     # baris DB + folder kerja
uv run renv status span-citation          # corpus + state project

1.6 Web cockpit (opsional)

uv run renv web            # http://127.0.0.1:8765

# atau pasang sebagai layanan on-demand lokal:
uv run renv web install    # build UI + https lokal

1.7 Cek cepat

uv run renv papers         # daftar paper di corpus
uv run renv status         # ringkasan corpus
uv run renv --help         # semua perintah
